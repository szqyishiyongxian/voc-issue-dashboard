## 详细介绍（可直接粘贴，约 700 字）

**把 VOC 会话表变成「先看排行、再下钻」的问题分析看板。**

客服与售后团队通常把客户声音沉淀在多维表格里，但几千条记录摊平成表格后，没有人能一眼看出「到底哪个产品、哪类问题最值得先解决」。这个插件把同一份数据重新组织成三级视图：先看产品线的产品问题量排行，点击某个产品后看它的一级 / 二级 / 三级标签收敛过程，最后落到具体会话与对应的知识链接。

**主要用法：**

- **产品排行**：按问题量降序横向排列所有产品，按产品线配色，条形长度即问题量占比。先看到「哪个产品问题最多」，而不是先看到一堆标签。
- **逐层下钻**：点击任意产品 → 标签排名从一级收敛到二级、三级 → 点击标签 → 明细表只剩这个范围下的会话。面包屑可随时回退。
- **热力矩阵**：切到矩阵模式后，产品线 × 一级标签排成热力表，色深即问题量，一眼看出一类问题集中在哪几条产品线。
- **对话明细**：点开任意一条会话，查看完整对话记录、用户诉求、满意度、客服与渠道，并可直接跳转命中的知识链接。
- **高频知识链接**：当前范围内被引用最多的知识页排行，用于判断哪些知识需要补充或更新。
- **团队视角**：按「兜底归属」切换 FAE / 培训组 / 增值服务组，或直接用关键词搜索标签、描述与型号。

**使用步骤：**

1. 在多维表格页面点击「添加组件」→「更多」→ 选择「VOC 问题分析看板」。
2. 在右侧配置面板选择多维表格数据源。插件会自动匹配数据表与所需字段（产品型号、一二级三级标签、兜底归属、问题描述、消息记录、知识链接、编号等），匹配完成后图表立即出图。
3. 保存后即为展示态，后续数据更新会自动刷新。

**需要帮助：** 若图表未出图，请确认所选数据表包含上述字段，且当前账号对数据表有查看权限。反馈与需求请联系插件维护者。

## 提交前命令

```bash
rm -rf node_modules dist
npm install
npm run build
```

构建产物应为 `dist/index.html` + `dist/assets/*.js` + `dist/assets/*.css`，单入口、无动态分包。
